# DataHost

DataHost è una piattaforma di file hosting personale che permette agli utenti
di caricare, gestire, visualizzare e condividere i propri file tramite
un'interfaccia web.

## Visualizzazione dei file

DataHost permette di visualizzare direttamente dal browser diversi tipi di
file, inclusi immagini e video.

![Visualizzazione di un video](images/file-preview.png)

## Condivisione dei file

Gli utenti possono condividere i propri file con altri utenti registrati
attraverso un'apposita finestra di condivisione.

![Condivisione di un file](images/file-sharing.png)
