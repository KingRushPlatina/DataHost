# DataHost

## Demo

### Condivisione dei file

È possibile condividere i propri file con altri utenti registrati tramite un'apposita finestra di condivisione.

![Condivisione di un file](images/Screenshot%20from%202026-08-15%2015-37-47.png)

### Visualizzazione dei file

DataHost permette di visualizzare i file direttamente dal browser, compresi video e immagini.

![Visualizzazione di un video](images/Screenshot%20from%202026-08-15%2015-39-27.png)

## Funzionalità

* **Registrazione e accesso** — creazione dell'account e autenticazione degli utenti.
* **Gestione degli utenti** — gestione degli account e dei relativi dati.
* **Sistema di ruoli** — distinzione tra utenti normali e amministratori.
* **Upload dei file** — caricamento dei file direttamente dal browser.
* **Gestione dei file** — visualizzazione e gestione dei file caricati.
* **Anteprima delle immagini** — visualizzazione delle immagini direttamente nell'applicazione.
* **Riproduzione dei video** — possibilità di riprodurre i video direttamente dal browser.
* **Supporto a diversi formati** — gestione di immagini, video e altri tipi di file.
* **Informazioni sui file** — visualizzazione di nome, dimensione, tipo e data di caricamento.
* **Download dei file** — possibilità di scaricare i file presenti nello storage.
* **Eliminazione dei file** — rimozione dei file caricati.
* **Condivisione dei file** — possibilità di condividere i propri file con altri utenti.
* **Gestione delle condivisioni** — visualizzazione degli utenti con cui un file è stato condiviso.
* **Rimozione delle condivisioni** — possibilità di revocare l'accesso a un file condiviso.
* **File condivisi con me** — visualizzazione dei file ricevuti da altri utenti.
* **Impostazioni** — configurazione delle impostazioni dell'applicazione.
* **Configurazione dello storage** — configurazione del percorso in cui vengono salvati i file.
* **Paginazione dei file** — suddivisione dei file in più pagine.
* **API protette** — protezione delle operazioni tramite autenticazione JWT.
* **Password sicure** — password protette tramite hashing con bcrypt.
* **Database MongoDB** — gestione persistente di utenti, file e condivisioni.
* **Interfaccia web** — accesso alla piattaforma direttamente dal browser.
* **Interfaccia responsive** — adattamento dell'interfaccia alle diverse dimensioni dello schermo.
* **Dashboard** — area principale per visualizzare e gestire i propri file.
* **Interfaccia ispirata a Google Drive** — organizzazione dei file e interfaccia pensate per offrire un'esperienza simile a un servizio di cloud storage.
